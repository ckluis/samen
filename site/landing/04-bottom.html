—Scope, stated on purpose

What this is not, stated as precisely as what it is.

A project that can draw its own boundary is one whose other claims you can price. Each limit below is written in the repo in the same words. When a reviewer finds a claim that outruns its evidence, the fix is a commit, and the retraction stays visible.

01 · Keyless lane

No live vendor is wired in CI.

Billing and email are proven against hermetic fakes and recorded transports through a real conformance suite, never a real account. Generated apps boot with both unconfigured and say so. The seams are proven; the wires are yours.

02 · Support access

Support can see PII.

Through a grant a second person approved, that expires on its own and that the tenant can audit. "Support never sees plaintext" was once on this page; it was false by construction and was retired.

03 · Verticals

The verticals are proof, not product.

driftwood (freight), pawchart (veterinary) and demo exist so the substrate must survive unrelated domains. They aren't for sale. If a vertical does something clever, that's a bug in the kernel.

04 · Leverage

188 lines is a mount number, not an app size.

pawchart mounts framework surfaces in about 188 authored lines; pawchart itself is about 3,900. An earlier page conflated the two, and the overclaim was corrected rather than reworded.

05 · Residency & distribution

US-only, and not on Hex yet.

One Postgres per host, no per-tenant region selection. The framework ships as path dependencies inside this monorepo; publishing waits on a stated trigger.

06 · Erasure's edge

Erasure can't reach what samen never wrote.

A spreadsheet someone exported, or a downstream system that stored its own plaintext, is outside the boundary. The page won't pretend otherwise.

—Two ways in

Run it in ten minutes, or read it for an afternoon.

Path A · Use it

Generate an app and make it prove itself.

You need Elixir 1.20 on OTP 29 and a local PostgreSQL with pgvector. No Docker, no API keys, no accounts.

$ git clone https://github.com/ckluis/samen && cd samen/samen_core$ mix samen.gen.app --module Harbor --prefix hb --abbrev hrb$ cd ../harbor && MIX_ENV=test bash ci.sh{{GEN_GATE_STEPS}}/{{GEN_GATE_STEPS}} steps ALL PASSED # zero hand-edits

If the generated app needs a fix from you to go green, the generator is broken, not your setup.
