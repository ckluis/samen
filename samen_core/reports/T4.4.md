- **Date:** 2026-07-07

- **Vision doc:** "The honest edges" break-glass bullet (`docs/samen-foundry.txt:951`):
  *"emergency break-glass … writes to a locally-durable, deferred-anchor audit — an
  append-only, hash-chained record on the operator node's own disk (fsync'd, not the
  central DB) that captures who/what/why before the reveal is granted. When the control
  plane returns, those entries are anchored into the WORM chain (and reconciled into
  aud_event); the chain detects any gap or tamper because each local entry carries the

  plaintext when the KMS itself is unreachable … if the KMS is also down the reveal

## What I built (all in `samen_core`; builds on T1.6/T2.9/T4.1/T4.2/T4.3, never duplicates)

- **`Samen.BreakGlass`** — the DISTINCT emergency reveal path. `reveal/1` enforces, in
  order: (a) who/what/why (`:reason` required, non-empty) → (2) single-role gate
  (`authorized?/1`, only `:operator_break_glass`) → (3) suspension gate → (4) breadth
  budget (records + checks) → (5) local audit write (who/what/why BEFORE the reveal) →
  (6) LIVE KMS decrypt via the SAME single vault chokepoint (`Samen.Vault.reveal/3`).
  KMS down ⇒ `{:error, :unavailable}` ⇒ deny (no bypass). Emits `[:samen, :break_glass,
  :reveal]`.
- **`Samen.BreakGlass.LocalAudit`** — the locally-durable, append-only, **hash-chained**,
  **fsync'd** record on the operator node's disk. `append/2` computes seq/prior_hash/hash
  off the file's own tail (the file IS the state), fsyncs (`:file.datasync/1`) every
  append, and does verify-on-read (each line embeds `SHA256(canonical)`; a tampered line
  is rejected). `verify_chain/1` detects edit/delete/gap. Reuses
  `Samen.AuditChain.Canonical` — the SAME deterministic canonicalizer the central chain
  uses, so a local entry and its reconciled central entry hash identically.
- **`Samen.BreakGlass.Reconciliation`** — anchors local entries into the T4.3 chain
  (`aud_chain`) AND `aud_event` on control-plane return, via `Samen.AuditChain.Writer.write/2`
  (reuse, not duplicate). **Verifies the local chain FIRST** — a tampered/gapped local
  file returns `{:error, {:local_tamper, _}}` and anchors NOTHING (fail closed across
  the local→central seam). Idempotent via `brc_break_glass_anchor` keyed on the local
  entry's content hash. `unanchored_count/1` + `emit_unanchored_signal/1` fire the R8
  monitor.
- **`Samen.BreakGlass.Budget`** — the per-operator **breadth budget** (N DISTINCT
  subjects per rolling window). `record_and_check/1` writes a `brl_reveal_ledger` row on
  EVERY reveal path (cross-path count — an operator can't dodge the budget via the
  emergency path), counts DISTINCT subjects in the window, and on breach auto-suspends
  the operator and returns `{:suspended, count}` so the tripping reveal is itself denied.
- **`Samen.OperatorPlane.Suspension`** — the auto-suspend flag (`osp_operator_suspension`).
  `suspended?/2` is the ONE predicate consulted by all three reveal paths; it fails
  closed (`on_error: true`). `clear/2` is explicit + manual (a suspension is not
  time-based, so a runaway loop can't wait it out). Suspend/clear emit token-only audit
  events into the chain.
- **Wiring into the other reveal paths (clause (d) — "all reveal paths deny incl.
  break-glass"):**
  - `Samen.Reveal.Grants.granted?/1` now denies a suspended operator BEFORE the grant
    check (`not suspended? and active?`);
  - `Samen.Impersonation.Sessions.open/1` refuses a suspended operator
    (`{:error, :operator_suspended}`).
- **`Samen.OperatorPlane.Actor`** — added the single `:operator_break_glass` role to the
  closed operator-role set (the "single break-glass role convention"). It may also
  impersonate (superset emergency role); its distinguishing capability is the emergency
  reveal.
- **Migrations** (samen_core test_repo + demo): `osp_operator_suspension` (partial
  UNIQUE — at most one active suspension per operator), `brl_reveal_ledger`,
  `brc_break_glass_anchor` (UNIQUE on local_hash). Token-only, not catalogued (mirrors
  the `imp_`/`rvg_` operator-plane kernel precedent).
- **Config** (`config/config.exs`): `:operator_suspension_repo`,
  `:break_glass_breadth_budget` (25), `:break_glass_breadth_window_seconds` (3600),
  `:break_glass_local_audit_path`.
- **Runbook:** `docs/runbooks/break-glass.md` (the R8 decision, the two drills, the
  single-role convention, reconciliation, tamper response, telemetry to wire).

## The precise "what survives what" contract (implemented exactly)

| Failure | Behavior | Test |
|---|---|---|
| Central audit / control-plane DB down | reveal COMPLETES; who/what/why durable LOCALLY; anchoring DEFERRED | DRILL 1 |
| KMS down | FAILS CLOSED (`:unavailable`); deny-RECOVERABLE (heals → same call succeeds); NO bypass even when the local audit is writable | DRILL 2 + no-bypass test |
| Operator suspended | DENIES (`:operator_suspended`); no emergency override | budget-breach test + routine/impersonation deny tests |
| No reason | REFUSES (`:reason_required`) before any write | clause-(a) red path |
| Local audit write fails | FAILS CLOSED (`{:local_audit_failed, _}`) | clause-(a) local-fail red path |

## Red paths (all must-fail, all confirmed failing-closed)

1. **Break-glass without reason** → `{:error, :reason_required}`; nothing written, no reveal.
2. **Non-break-glass actor** (support / readonly / tenant) → `{:error, :not_authorized}`.
3. **Local-audit write failure** (parent path is a file) → `{:error, {:local_audit_failed, _}}`.
4. **KMS down** → `{:error, :unavailable}` (fail closed); heals → succeeds (deny-recoverable).
5. **KMS down with a fully-writable local audit** → still denies (no bypass).
6. **Local-entry tamper at reconciliation** (edited line) → `{:error, {:local_tamper,
   {:tampered_line, _}}}`; NOTHING anchored.
7. **Deleted middle local entry (gap)** at reconciliation → `{:error, {:local_tamper,
   {:seq_gap | :broken_link, _}}}`; NOTHING anchored.
8. **Budget breach** → the tripping reveal denies `{:error, :budget_exceeded}`; operator
   auto-suspended; every subsequent break-glass denies `{:error, :operator_suspended}`.
9. **Suspended operator on the ROUTINE path** → `Grants.granted?/1` returns false.
10. **Suspended operator on the IMPERSONATION path** → `open/1` → `{:error, :operator_suspended}`.
11. **Unanchored telemetry** fires with a positive count while entries await anchoring;
    returns to zero after reconciliation.

## Anti-tautology probes (HARD RULE 2)

Backed up to a project-local scratch dir OUTSIDE `/tmp` (`.t44_antitaut_scratch/`, since
removed). Both are code-sabotage probes on the load-bearing fail-closed mechanisms named
in the task:

- **Fail-closed KMS path** — sabotaged `Samen.BreakGlass.live_kms_reveal/1` to return
  `{:ok, "SABOTAGED-plaintext"}` (bypass the vault/KMS entirely). Re-ran the suite:
  **6 tests flipped to FAILING** — DRILL 2 (KMS-down deny), the no-bypass test, the
  KMS-down anti-tautology positive control, and the three happy-path reveals (which
  asserted the ACTUAL decrypted plaintext, not the sabotage string). Reverted from
  backup → `diff` identical, 0 `SABOTAGED` markers.
- **Breadth budget** — sabotaged `Samen.BreakGlass.Budget.record_and_check/1` to never
  trip (`if false and count > budget()`). Re-ran: the **budget-breach red path flipped
  to FAILING** (the 4th distinct-subject reveal returned plaintext instead of
  `:budget_exceeded`, and the operator was not suspended). Reverted → `diff` identical,
  0 `SABOTAGED` markers.
- **Result:** the KMS-down deny and the breadth budget are non-vacuous discriminators,
  not always-pass/always-deny. Scratch dir removed; both suites re-run green.

In-test positive controls also ship (the KMS-down deny is NOT an always-deny — with the
KMS up the same call succeeds; the budget is NOT an always-suspend — within budget the
operator stays un-suspended).

## R8 decision (plan risk register) — the local-disk durability residue

**Decision: persistent-volume mount (primary) + accept-and-monitor (backstop).** Recorded
in `docs/runbooks/break-glass.md` §5.

- **Primary:** production mounts a persistent volume per operator node and points
  `:break_glass_local_audit_path` at it (on Fly: a `fly volume` on the operator process
  group), so a reveal written during an outage survives machine restart/redeploy and is
  present when reconciliation runs. The volume is outside the Postgres PITR surface —
  consistent with the external-KMS decision.
- **Backstop:** a volume can still be lost, so we do NOT pretend the window is zero.
  `Reconciliation.emit_unanchored_signal/1` fires `[:samen, :break_glass, :unanchored]`
  with the count of local entries not yet anchored; wire it to a cron and alert on a
  sustained `> 0`. The residue is documented, bounded, and observable — never silent.
- **Why not two synchronous local nodes** (the plan's other option): persistent-volume +
  monitor keeps the single-writer fsync discipline on the emergency path and avoids
  cross-node consensus that itself fails in new ways during a partition; the two-node
  synchronous write is the documented upgrade if a future regime requires
  zero-single-node-loss.

## Seam honesty (plan HARD rule)

- **No AWS/S3 here** — the T4.3 anchor (which reconciliation seals into) already ships as
  behaviour + faithful `LocalWorm` adapter + `S3ObjectLock` skeleton; T4.4 reuses that
  seam unchanged (reconciliation writes to `aud_chain`, which the T4.3 seal cron anchors).
- **KMS** — break-glass calls the real `Samen.Kms.adapter().unwrap/1` via
  `Samen.Vault.reveal/3`; the KMS-down drill uses `Samen.Kms.FileBacked.simulate_outage/1`
  (a faithful local outage of the external store), never a faked pass.
- **Within-window "control-plane down" drill** — DRILL 1 asserts the reveal completes and
  the who/what/why is durable LOCALLY (unanchored, residue window open) rather than
  requiring a literal central-DB partition in CI; the reconciliation tests then prove the
  deferred anchor lands and is gap/tamper-detected. Honest scope stated.
