**Status:** GREEN. All four sub-deliverables shipped; red paths + anti-tautology
probes confirmed load-bearing; both suites and the 11-step demo CI gate green.

## Scope delivered (plan T3.8; vision doc §core Tier-1 bag, malleability ladder rung 2)

### (a) The `xxx_custom` jsonb bag — **opt-in extension, documented decision**
The bag is an ordinary `attribute(:custom, :map)` a resource (or the
`Samen.Fragments.CorePerson` fragment) declares; the base macro's abbrev
transformer prefixes it to `xxx_custom` (`tcf_custom`, `per_custom`, `cmp_custom`).
**Decision: opt-in, not universal** — declaring the `:custom` attribute is what
opts a resource in. Rationale documented in
`Samen.Transformers.MaterializeCustomFields` moduledoc: the vision doc shows
`xxx_custom` on person/company-shaped records, not on join/config-row tables;
forcing a bag everywhere would widen the sealed jsonb zone for no benefit. When
the bag IS present, the validation change is injected automatically (not left to
the resource author — a bag without validation would be a containment hole).

### (b) `tnt_field` runtime metadata + validated-at-write
- `tnt_field` table (`Samen.CustomFields.FieldRow`): org-scoped rows
  `(tnt_org_id, tnt_table_name, tnt_field_name, tnt_type, tnt_constraints, tnt_pii_declared)`,
  UNIQUE on `(org, table, field)`. Plain Ecto DDL (same bootstrap reasoning as
  `tam_table`/`fld_field`). Created by `Samen.Migration.create_tnt_field_table/0`.
- `Samen.CustomFields.define_field/2` — defines/upserts a field with a **bounded**
  type (`string|integer|number|boolean|date|enum`) + per-type constraints;
  fail-closed at define time on an unknown type or an `enum` with no `one_of`.
- `Samen.CustomFields.Change` (injected by `Samen.Transformers.MaterializeCustomFields`)
  validates the **whole bag** in `before_action` against the org's `tnt_field`
  defs: an undefined key, wrong type, or constraint violation is **rejected at
  write** via `Ash.Changeset.add_error` — the bad bag never reaches Postgres.

### (c) Catalogued — **tnt-namespaced surface, documented vs `fld_field`**
`tnt_field` IS the tenant catalog surface, the `tnt`-namespaced sibling of
`fld_field`. Distinction documented in both moduledocs and the honest edge:
- `fld_field` — **system** columns, org-agnostic, compile-time provable.
- `tnt_field` — **tenant** custom fields, org-scoped, validated-at-write.

`mix samen.verify.tnt_catalog` enforces parity in two directions:
1. `tnt_field → tam_table` (no orphan custom field on a ghost table);
2. **bag keys → `tnt_field`** (no *invisible* custom field — every jsonb bag key
   present in any row must have a `tnt_field` row for that row's org). Wired as
   step 11/11 of `demo/ci.sh`.

### (d) Containment — the honest edge, **fail-closed default**
`Samen.CustomFields.classify_containment/2`: a value matching
`Samen.PiiValueShape.classify_id_value/1` (email/SSN/phone/name shapes) on a field
NOT declared `pii_declared: true` is **REJECTED** at write. Default is fail-closed
(`pii_declared: false`). Declaring `pii_declared: true` is an org knowingly
accepting plaintext-in-bag: it lifts the *rejection* only, it does **not** route
the value to the vault (Tier-1 is contained, not vault-protected — the seam is
named, not hidden). The jsonb zone is **sealed**: `tnt_field` describes bag *keys*,
the bag is a plain `:map` column, and a test asserts **no FK from any system table
targets `tcf_custom`**.

## Simulation seams / honest notes
- No AWS/Neon needed. `tnt_field` is local Postgres; the vault is untouched (Tier-1
  values are contained in the bag, never vault-routed — that IS the design).
- The containment check is a **value-shape heuristic**, not a taint proof (same
  honest caveat `Samen.PiiValueShape` already documents). The load-bearing seal is
  structural: no FK from system tables into bag content, fail-closed rejection of
  PII-shaped values, and a durable CI parity backstop. Documented in the moduledoc
  as "validated-at-write and contained — not the same proof as the system core."
- The `tnt_catalog` bag-scan uses `jsonb_object_keys`; it skips org-less tables
  (Tier-1 is org-scoped by definition) and tables with no bag column.
