## What was built

Extensible **tier registry** so the Phase-2 oracle (T2.9) adds
`cdc_mirror`/`rollup`/`trace_sink` tiers without touching the harness:

- `Samen.NoPlaintextPii.Tier` — behaviour (`tier_name/0`, `mode/0` = `:ci` |
  `:post_shred`, `describe/0`, `check/1`). CI mode runs only `:ci` tiers; a
  `:post_shred` tier registered today is inert until T2.9 drives it.
- `Samen.NoPlaintextPii.Finding` — `:violation` (fails build) | `:exempt`
  (listed, never fails — clause (d)).
- `Samen.NoPlaintextPii.Context` — shared read-model: repo, resources,
  vault-routed `{table,column}` set (from `Samen.Pii.Info`, declaration-keyed),
  valid `non_pii!` exemptions (distinct-reviewer), deps. `plaintext_pii_type?/1`
  keys on `Samen.Pii.Classification` (mask-unknown-by-default → fail safe).
- `Samen.NoPlaintextPii` — orchestrator: `run/1`, `default_tiers/0`,
  `violations/1`, `exemptions/1`. A tier that raises → fail-closed violation.

CI-mode tiers (the surfaces that EXIST so far):

- **VaultDeclarations** (clause a): every `pii_attribute` materializes to the
  `Samen.Type.VaultField` token type AND its physical column is a token string
  (`varchar`/`text`), never a plaintext type. Declaration-keyed, not `pii_`-prefix.
- **AuditRows** (clause b): the T1.6/T1.7 projections (`rvl_reveal_audit`,
  `rvg_reveal_grant`, `rvq_reveal_request`, `era_erasure_report`) carry only
  bounded-ID/token/enum/timestamp/JSON columns. Two gates: a PII-name gate AND a
  fail-closed allow-list gate (an unrecognised text column is a leak until
  removed/tokenised/`non_pii!`-reviewed).
- **Catalog** (clause b): every vault column's `fld_field.fld_type` is the token
  type (not `String`/`Date`/`FullName`); the catalog storage tables carry only
  metadata.
- **LogTelemetry** (clause c): config-level — if `opentelemetry_ecto` is a
  dependency, `db_statement` must be `:disabled` (else fail closed). No OTel dep
  is pinned today, so this passes now but fails the moment a host adds it without
  disabling `db_statement`.

Mix task `mix samen.verify.no_plaintext_pii` (CI mode; `--repo`/`--domain` only —
NO `--subject`/`--tiers`), on the S0.6 harness (`:erlang.halt/1`). Prints the
exempt list (clause d) then halts non-zero iff any `:violation`.
