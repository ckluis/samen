## Scope delivered

### (a) `docs/guides/llm-grounding.md`
How an agent consumes `schema.dict.json` to ground on the real model (the two-name
identity model, the `pii` flag keyed on the declaration), and the authoring loop:
**add a resource → run the verifier gate → the gate is the agent's correctness

heuristic, `pii_reads` dataflow-not-taint, storage-not-semantic checks) and the
grounding-artifact-sufficiency section (part c).

### (b) `samen_core/test/agent_authoring_eval_test.exs` — the runnable eval (13 tests)
Models "an agent authored these changes" and APPLIES each seeded change to a scratch
host (the `SamenCore.TestRepo` fixture DB in-sandbox / a project-local scratch source
dir / an introspection-only fixture), then asserts the gate's **exact exit behavior**
via the SAME `check/*` / `violations/*` / `scan/*` entry points each `mix
samen.verify.*` task runs before `Samen.Verifier.halt_if_violations/2` (which halts
iff violations ≠ []). The six cases + the gate's response to each:

| # | seeded wrong | owning verifier | exit | how applied |
|---|---|---|---|---|
| 1 | a **correct** resource (vaulted PII, guarded FK, no leak) | whole gate | **0 (passes)** | `RevealPerson` + `SameOrgFkFixture.Guarded` — the non-vacuous positive control |
| 2 | a hallucinated / uncatalogued column | `catalog_parity` + `column_refs` | 1 | scratch-dir source ref `drv_license` + in-sandbox `ALTER TABLE … ADD COLUMN com_hallucinated` |
| 3 | net-new plaintext PII (`attribute :ssn, :string`) | `pii_classify` | 1 | `PiiClassify.PersonRecord` (plain `:ssn`), empty baseline+registry |
| 4 | an unprefixed physical column | `prefixes` | 1 | in-sandbox `ALTER TABLE com_contact ADD COLUMN raw_ssn` |
| 5 | a vault value logged outside `:reveal` | `pii_reads` | 1 | `PiiReads.scan_source` of a `Logger.info(subject.rvp_emails)` outside a reveal action |
| 6 | a `belongs_to` with no `SameOrgFk` guard | `same_org_fk` | 1 | `SameOrgFkFixture.Unguarded` |

Cases 2–6 are the eval's must-fail **red paths**; case 1 is the must-pass control.
A `@rubric` scores each case (owning verifier + expected exit); a final test asserts
all six score `:pass`. **Case 2 is also driven through a real `System.cmd/3` child OS
process** to observe the true `:erlang.halt(1)` exit code end-to-end — exit **1** on
the seeded uncatalogued column (diagnostic names `com_agent_ghost`), exit **0** on
the clean host.
