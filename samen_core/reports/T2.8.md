## Deliverables

### (a) `Samen.Metrics` — bounded-cardinality telemetry_metrics definitions

**File:** `samen_core/lib/samen/metrics.ex`

Six `Telemetry.Metrics` definitions using ONLY bounded label dimensions:
- `samen.action.duration` — distribution, tags: `action, result, tenant_tier`
- `samen.action.count` — counter, tags: `action, result, tenant_tier`
- `samen.http.request.duration` — distribution, tags: `route, result`
- `samen.pool.saturation.events` — counter, tags: `action`
- `samen.oban.job.duration` — distribution, tags: `action, result`
- `samen.oban.job.queue_time` — distribution, tags: `action`

Forbidden tag keys: `org_id`, `actor_id`, `subject_id` — exported from `forbidden_tag_keys/0` for the label-lint scanner.

`hash_tenant_tier/2` buckets a raw tier atom into the bounded set `{:free, :starter, :pro, :enterprise, :unknown_tier}` — the `org_id` is accepted as a parameter but NEVER appears in the output label, keeping the dimension cardinality at 5 regardless of tenant count.

**Exemplar support:** `exemplar_trace_id/0` extracts the current OTel trace_id from the active span context as a 32-char hex string. Where the reporter supports it (`TelemetryMetricsPrometheus ≥ 1.1, exemplars: true`), include this in the measurement map under `:trace_id` on latency histogram events so a spiking P95 links to an example trace.

### (b) Label-lint CI check

**File:** `samen_core/lib/mix/tasks/samen.verify.metric_labels.ex`

`mix samen.verify.metric_labels` scans all metric definitions from configured modules for forbidden tag keys (`org_id`, `actor_id`, `subject_id`). Exits non-zero with a descriptive message if any are found.

Usage in `ci.sh`: add `mix samen.verify.metric_labels` after the compile step.

### (c) `Samen.Metrics.ContentionHandlers` — pool and Oban contention handlers

**File:** `samen_core/lib/samen/metrics/contention_handlers.ex`

Three handlers:
1. **Ecto pool saturation handler** — listens to `[<repo_prefix>, :query]`; fires `[:samen, :pool, :saturation]` when `queue_time > threshold_ms` (default 50 ms). Makes pool checkout wait visible as a Prometheus counter — not a mystery.
2. **Oban job stop handler** — listens to `[:oban, :job, :stop]`; re-emits as `[:samen, :oban, :job, :stop]` with bounded tags (`action`, `result`, `duration`, `queue_time`).
3. **Oban job exception handler** — same re-emit with `result: :error`.

`attach/1` is called at `Application.start/2`. Tested via synthetic `[:samen_test, :repo, :query]` events (see simulation seam note).
