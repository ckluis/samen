# T6.5 — The optional ClickHouse CDC tier (mechanism + local simulation + skeleton)

**Status:** GREEN. All suites (samen_core 827, demo, driftwood, PawChart) + root
`ci.sh` pass. `mix test --warnings-as-errors` green in samen_core.

## What shipped

The optional ClickHouse CDC analytics tier (plan T6.5; vision doc lines 635/637):
opt-in per product, **default off**; the mirror carries **token-blind rows**
(vault-FK `vt_*` tokens, bounded IDs, enums, timestamps, numbers), never plaintext;
you **never read a "current" value** from it.

There is no ClickHouse in this environment, so this is the *mechanism* + a
*faithful local simulation* + a *production skeleton* — never a faked pass.

### (a) `Samen.Cdc` behaviour + config-flagged mirror pipeline

- `Samen.Cdc` — the behaviour (`ensure_mirror/2`, `mirror_row/4`,
  `mirrored_columns/2`, `scan_no_plaintext/2`, `read_current/3`) + facade
  (`enabled?/0`, `mirror/3`, delegates). Default off; `mirror`/`ensure_mirror` are
  no-ops returning `{:ok, :disabled}` when off.
- `Samen.Cdc.Projection` — the **load-bearing, adapter-independent** token-blind
  projection. `project/1` excludes plaintext PII columns by construction (via the
  shared mask-unknown `Samen.Pii.Classification` oracle); `assert_no_plaintext!/2`
  RAISES `PlaintextInProjectionError` when a plaintext column is explicitly named
  for the mirror (the production analogue of a mis-scoped ClickPipes allow-list).
- `Samen.Cdc.LocalPostgres` — the LOCAL SIMULATION: mirrors the projection into a
  second local Postgres schema (`cdc_mirror`) standing in for ClickHouse. Proves
  the projection excludes `pii_` plaintext columns (the mirror table is built from
  the projection) and that post-shred the mirror holds only dangling `vt_*` tokens.
- `Samen.Cdc.ClickHouse` — the PRODUCTION SKELETON (`ecto_ch`, config-flagged, NOT
  connected). Callbacks fail closed (`:not_connected`; `scan_no_plaintext` returns
  `{:leaks, …}`) so an enabled-but-unconnected mirror never reports clean. Inline
  operator TODO for real ClickPipes wiring.
- `Samen.Cdc.Config` — opt-in/default-off wiring (`config :samen_core, :cdc,
  adapter:, repo:, schema:`); legacy `:cdc_mirror_repo` back-compat as a
  fail-closed-when-unscanned seam.

### (b) The destruction-oracle `cdc_mirror` tier — ACTIVATED (was a T2.9 stub)

`Samen.NoPlaintextPii.Tiers.PostShred.CdcMirror` now performs a real content scan
when the tier is on: **schema assertion** (every physical mirror column ∈ the
token-blind projection; a rogue plaintext column is a `:violation`), **post-shred
content scan** (no mirror token decrypts; dangling-token count reported), and a
**never-read-current attestation**. Off ⇒ single `:pass`. Legacy configured-but-
unscanned ⇒ fail-closed `:violation`. Registered in `post_shred_tiers/0`, driven by
`--tiers all`.

### (c) The never-read-current lint/guard + doc

- Runtime chokepoint: every adapter's `read_current/3` ALWAYS raises
  `Samen.Cdc.NeverReadCurrent.Violation`.
- Build-time lint: `mix samen.verify.never_read_current` +
  `Samen.Cdc.NeverReadCurrent` AST scanner — flags any CDC-repo read
  (`all/get/one/aggregate/…`) in a module not marked `@cdc_analytics_read true` /
  `use Samen.Cdc.Analytics`. Tier off ⇒ vacuously-but-honestly satisfied (not a
  false green). Wired into driftwood's gate as step 16b.
- Doc: `docs/cdc-analytics-tier.md`.

### (d) Opt-in / default-off wiring

`Samen.Cdc.Config` (§above). Verified: samen_core, demo, driftwood, PawChart all

## Red paths (HARD RULE 2) — all present, all fail closed

- **RP-A** — a plaintext PII column named in a mirror request ⇒
  `PlaintextInProjectionError` (`cdc_mirror_test.exs`).
- **RP-B** — a plaintext column physically in the mirror table (bypassing the
  projection) ⇒ oracle schema-scan `:violation`.
- **RP-C** — post-shred a mirror token that still decrypts ⇒ oracle content-scan
  `:violation`.
- **RP-D** — legacy `:cdc_mirror_repo` with no `:cdc` adapter ⇒ fail-closed gap.
- **never-read-current** — `read_current/3` raises; an un-marked (incl. aliased)
  CDC-repo read ⇒ `:current_read` violation (`cdc_never_read_current_test.exs`).
