## Red paths (all fail closed, tested)

1. **Impersonation without a reason REFUSES** — `open/3` → `{:error, :reason_required}`
   before any write (nil/""/whitespace); DB `NOT NULL` on `imp_reason` backstops.
2. **Expired session denies mid-flight** — `active?/3` / `Scope.for_session/3` check
   `expires_at > now` PER REQUEST; the row lingers open (deny-on-read, not cleanup).
3. **:reveal under impersonation without a second-party grant DENIES** — the reveal
   seam (`Samen.Reveal.reveal/5`) consults the T1.6 grant model, which denies for the
   operator id with no live grant; never touches the vault.
4. **PII masked through LiveView/JSON/CSV under impersonation** — the impersonation
   scope carries no grant → `%Masked{}` renders `••••` through every egress; the T3.11
   resolver keeps it `••••` (present-but-masked, doc §control).
5. **A tenant can see the impersonation record** — `list_for_org/2` / `list_for_scope/1`
   (who/when/reason/expiry/active?, tokens only).
6. **Operator RBAC** — `:operator_readonly` + non-operators may not impersonate;
   `Actor.new/2` refuses an unknown role.

## Doc parity / design notes

- **Mirrored, not duplicated.** The session runtime reuses the T1.6 grant shape
  (bounded `expires_at`, same-tx auto-cleanup enqueue, deny-on-read per request, no
  renew-in-place) and the T2.2 `aud_event` tier and the T3.11 egress resolver. No new
  audit table (ADR-004 §5 honored). No new reveal machinery — impersonation is
  deliberately grant-LESS; unmasking is the separate T1.6 path (mutually exclusive).
- **Two operator postures, both correct.** The API operator-KEY posture (T3.11) is
  ABSENT (omit the field); the impersonation-UI posture (T4.1, doc §control) is
  `••••` PRESENT-but-masked. The `:impersonation` actor marker distinguishes them; the
  T3.11 key tests are unchanged (verified: `api_two_key_classes_test` still 14 pass).
- **Single-org only.** T4.1 keeps to single-org operator paths. Cross-tenant AGGREGATE
  reads (MRR across tenants), the token-blind aggregate actor + `NoPiiColumns` verifier,
  and the mutual-exclusion-with-`:reveal` proof are T4.2 (deliberately deferred).
- **Break-glass, hash-chained audit + WORM, k-anon floors** are T4.3–T4.5 — not here.
